# 타이타닉 데이터 분석 (NumPy · Pandas 실전 프로젝트)

> "누가 살아남았을까? 그리고 그 이유는?"

넘파이·판다스 기초를 마친 학습자가 타이타닉 승객 891명의 데이터로 **데이터 분석의 전체 흐름**(불러오기 → 결측치 처리 → 그룹 분석 → 파생 변수 → 시각화 → 규칙 기반 예측)을 경험하는 수업 자료입니다.

## 교안에서 다루는 인사이트 5가지 (10장)

1. **성별은 등급보다 강했다** — 3등석 여성(50.0%)이 1등석 남성(36.9%)보다 많이 살았다.
2. **"어린이 먼저"에도 등급의 벽이 있었다** — 1·2등석 남자아이 12명 전원 생존, 3등석 남자아이는 39.3%.
3. **가족은 2~4명일 때 가장 유리했다** — 5명 이상 대가족 62명 중 54명이 3등석, 이들의 생존율은 7.4%.
4. **항구가 사람을 살린 것이 아니다** — C 항구의 높은 생존율은 1등석·여성 비율이 높았던 탓(교란 변수).
5. **빈 값도 정보다** — 객실 번호 기록률은 1등석 81%, 3등석 2.4%. 결측 여부 자체가 사회적 위치를 보여 준다.

## 데이터 분석 조언 7가지 (11장)

질문을 먼저 쓴다 · 데이터를 먼저 의심한다 · 결측치는 "왜 비었나"부터 · 한 변수로 결론 내지 말고 쪼개 본다 · 기준선과 비교하고 안 본 데이터로 검증한다 · 상관을 인과로 말하지 않는다 · 결과는 "그래서?"로 전달한다

## 실행 환경

```bash
pip install numpy pandas matplotlib seaborn
```

예제 코드는 데이터를 `https://raw.githubusercontent.com/sinaboro/data/main/titanic_kaggle.csv`에서 바로 내려받습니다. 인터넷이 안 되면 `DATA_URL = 'titanic.csv'`로 바꿔 쓰세요.

## 교안 PDF 다시 만들기

```bash
pip install numpy pandas matplotlib seaborn scikit-learn
python handout_src/build.py
```

`build.py`는 CSV로 분석을 다시 돌려 `handout_src/figures/`의 그림을 그리고, 크롬(또는 엣지) 헤드리스로 `handout.html`을 인쇄해 `타이타닉_데이터분석_교안.pdf`를 만듭니다. 그래프 한글 글꼴은 맑은 고딕(Windows) 기준입니다.
